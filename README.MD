# Network Recon Tool

This is a fast, multi-threaded Python script designed for network reconnaissance. It helps administrators and security testers discover open ports, analyze network traffic, and identify potential vulnerabilities efficiently.


## Features
* **Multi-Threading:** Utilizes Python's `threading` module for extremely fast and concurrent port scanning.
* **Robust Networking:** Built directly on Python's `socket` library for reliable TCP connections.
* **Input Validation:** Smart handling and validation of IP addresses before execution to prevent crashes.
* **Interactive CLI:** Clear and easy-to-use Command Line Interface.

## Prerequisites
Before you begin, ensure you have met the following requirements:
* **Python 3.x:** Installed on your local machine (Windows, Linux, or macOS).
* **Git:** (Optional) to clone this repository.


## Usage

1. Clone this repository to your local machine:
```bash
git clone https://github.com/saifsabah666-sudo/Network-Recon-Tool.git
```
2. Navigate to the project directory:
```bash
cd Network-Recon-Tool
```

3. Run the tool using Python:
```bash
python net_recon.py
```
